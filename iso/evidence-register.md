## Evidence Rules

- Evidence must show operation, not only intent.
- Evidence should include date, owner, source system, and result.
- Screenshots are acceptable only when API or exported evidence is unavailable.
- Secrets, tokens, private keys, and raw customer data must not be stored as evidence.
